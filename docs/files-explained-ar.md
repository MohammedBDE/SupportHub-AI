## الملفات الرئيسية (جذر المشروع)

**`README.md`**
- واجهة المشروع على GitHub.
- بشرح المشروع، طريقة التشغيل، والصور.
- أول شي بشوفه أي حدا بفتح الريبو.

**`CLAUDE.md`**
- قواعد العمل اللي اتفقنا عليها.
- مثل: ممنوع تعليقات بالكود، واشرح قبل ما تكتب.
- مش جزء من البرنامج، هو "دستور" للتطوير.

**`Support_Ticket_System_Project_Guide.md`**

- فيه الخطة اليومية والأسئلة المتوقعة.
- مرجع للتعلّم، مش كود.

**`.env.example`**
- نموذج لملف الأسرار بدون قيم حقيقية.
- بوضّح شو المتغيرات المطلوبة (قاعدة البيانات، JWT، مفتاح Claude).
- اللي بنزّل المشروع بنسخه لـ `.env` وبعبّي قيمه.

**`.gitignore`**
- قائمة ملفات Git لازم يتجاهلها.
- أهمها `.env` (فيه مفتاح صاحبك) و `node_modules`.
- بحميك إنك ترفع أسرار على GitHub بالغلط.

**`docker-compose.yml`**
- بشغّل ٣ حاويات مع بعض: قاعدة البيانات، الباك إند، الفرونت إند.
- أمر واحد `docker compose up` بدل ما تشغّل كل إشي لحال.
- جاهز للمستقبل لما تفعّل الـ SVM من الـ BIOS.

## الباك إند (`backend/`)

**`backend/package.json`**
- هوية مشروع الباك إند وقائمة المكتبات.
- فيه أوامر مثل `npm start` و `npm run seed`.
- npm بقرأه عشان يعرف شو ينزّل.

**`backend/Dockerfile`** و **`backend/.dockerignore`**
- وصفة بناء حاوية Docker للباك إند.
- بتحدد نسخة Node وشو ينسخ جوّا الحاوية.
- الـ `.dockerignore` بمنع نسخ `node_modules` و `.env` للحاوية.

**`src/server.js`**
- نقطة البداية — أول ملف بشتغل.
- بجهّز Express، بربط المسارات (`/auth`, `/tickets` ...) ومعالج الأخطاء.
- فيه `/health` عشان تتأكد إنه السيرفر شغّال.

**`src/config.js`**
- مكان واحد لكل الإعدادات والثوابت.
- بقرأ من `.env` وبعرّف القيم المسموحة (التصنيفات، الأولويات، الحالات، الأدوار).
- إذا بدك تضيف تصنيف جديد، بتبلش من هون.

### قاعدة البيانات (`src/db/`)

**`db/connection.js`**
- الاتصال بـ PostgreSQL عن طريق pool (مجموعة اتصالات جاهزة).
- بوفّر `query` للاستعلامات و `withTransaction` للعمليات اللي لازم تنجح كلها أو تفشل كلها.
- كل ملفات الباك إند بتحكي مع القاعدة من خلاله.

**`db/schema.sql`**
- تصميم الجداول الأربعة: `users`, `tickets`, `ticket_replies`, `knowledge_base`.
- فيه القيود (CHECK) اللي بتمنع تصنيف غلط يدخل القاعدة.
- وفيه الفهارس (indexes) اللي بتسرّع البحث.

**`db/schema-vector.sql`**
- إضافة اختيارية لـ pgvector (البحث بالمعنى).
- بضيف عمود embedding وفهرس للبحث السريع.
- مش مفعّل حالياً لأنه ما عنا مفتاح Voyage.

**`db/seed.js`**
- بعبّي القاعدة ببيانات تجريبية واقعية.
- موظفين، ٥٠ تذكرة، مقالات مساعدة، وردود.
- عشان الداشبورد والصور يبينوا حقيقيين.

### الحماية (`src/middleware/`)

**`middleware/authenticate.js`**
- "البوّاب": بتأكد إنه معك JWT صالح.
- بقرأ الـ token من هيدر `Authorization: Bearer ...`.
- إذا مش صالح أو منتهي → `401`.

**`middleware/authorize.js`**
- بفحص **الدور** بعد ما عرفنا مين أنت.
- `requireAdmin` بسمح بس للأدمن.
- مثال: تسجيل موظف جديد أو شوف الإحصائيات = أدمن بس.

**`middleware/errorHandler.js`**
- مكان واحد بمسك كل الأخطاء.
- `HttpError` لأخطاء متوقعة (400, 404)، وأي خطأ غير متوقع → `500` بدون تفاصيل حساسة.
- كمان بردّ `404` للمسارات اللي مش موجودة.

### نقاط الـ API (`src/routes/`)

**`routes/auth.js`**
- تسجيل الدخول `/login` وإرجاع JWT.
- تشفير الباسوردات بـ bcrypt، وحماية من timing attacks.
- كمان `/me` (مين أنا) و `/register` و `/users` للأدمن.

**`routes/tickets.js`** (أكبر ملف)
- إنشاء تذكرة → بتتصنّف بـ AI تلقائياً.
- عرض/بحث/فلترة، تغيير الحالة، تعيين موظف.
- `/suggest-reply` (اقتراح رد بـ AI) و `/replies` (حفظ الرد اللي انبعت).

**`routes/knowledgeBase.js`**
- إدارة مقالات المساعدة (عرض، إضافة، تعديل، حذف).
- الإضافة والتعديل للأدمن بس.
- هاي المقالات هي "المصدر" اللي الـ AI بعتمد عليه بالرد.

**`routes/analytics.js`**
- أرقام الداشبورد للأدمن.
- عدد التذاكر، متوسط أول رد، توزيع التصنيفات، الترند اليومي.
- ونسبة الردود اللي انبعتت من AI بدون تعديل.

### الذكاء الاصطناعي والبحث (`src/services/`)

**`services/anthropicClient.js`**
- بجهّز الاتصال بـ Claude API مرة وحدة.
- إذا ما في مفتاح → بيرجع `null` والنظام بكمّل بدون AI.
- وفيه دالة بتطلع الـ JSON من رد Claude.

**`services/ticketClassifier.js`**
- بيبعت عنوان ونص التذكرة لـ Claude.
- بيرجع: التصنيف، الأولوية، ونسبة الثقة — بشكل JSON مضمون (schema).
- وبعدين بتحقق من النتيجة بالسيرفر قبل ما تنحفظ.

**`services/knowledgeSearch.js`**
- بدوّر على أنسب ٣ مقالات لمشكلة التذكرة.
- بستعمل البحث النصي (full-text)، أو البحث بالمعنى (vector) إذا متوفر.
- إذا فشل البحث بالمعنى → برجع للنصي تلقائياً.

**`services/embeddingProvider.js`**
- بحوّل النص لأرقام (embedding) عن طريق Voyage.
- هاي الأرقام بتخلي البحث يفهم المعنى مش بس الكلمات.
- اختياري — بدون مفتاح بشتغل النظام عادي.

**`services/replySuggester.js`** (قلب الـ RAG)
- بياخد التذكرة + المقالات اللي لقيناها ويبعتهم لـ Claude.
- بيطلب منه يكتب رد **من المقالات بس** ويذكر أرقامها.
- السيرفر بتأكد إنه الأرقام حقيقية — فما بيقدر يخترع مصدر.

## الفرونت إند (`frontend/`)

**`frontend/package.json`**
- قائمة مكتبات الواجهة (React, Router, Recharts, Tailwind).
- أمر `npm run dev` بشغّل الموقع.
- نفس فكرة package تبع الباك إند.

**`index.html`**
- الصفحة الوحيدة اللي بتنفتح بالمتصفح.
- فيها `div` فاضي React بيعبّيه.
- هاد معنى "Single Page Application".

**`vite.config.js`**
- إعدادات Vite (أداة التشغيل والبناء).
- بحوّل طلبات `/api` للباك إند على بورت 3000.
- عشان ما نتعب مع مشاكل CORS وقت التطوير.

**`Dockerfile`** و **`nginx.conf`** و **`.dockerignore`**
- بيبنوا الموقع ويقدّموه عن طريق nginx داخل حاوية.
- nginx بيرجّع `index.html` لأي رابط (عشان React Router).
- وبيحوّل `/api` للباك إند.

**`src/main.jsx`**
- نقطة بداية React.
- بركّب `App` داخل الصفحة ومعه الـ Router و AuthProvider.
- ملف صغير جداً، ما فيه منطق.

**`src/App.jsx`**
- خريطة الصفحات: أي رابط بفتح أي صفحة.
- مثال: `/tickets` → صفحة التذاكر، `/dashboard` → للأدمن بس.
- بلفّ الصفحات المحمية بـ `ProtectedRoute`.

**`src/index.css`**
- ملف التنسيق الرئيسي.
- بشغّل Tailwind.
- كل التصميم الباقي بكلاسات Tailwind داخل المكونات.

**`src/api/client.js`**
- كل التواصل مع الباك إند من مكان واحد.
- بيضيف الـ token لكل طلب تلقائياً وبخزّنه بالمتصفح.
- إذا رجع `401` → بيطلعك لصفحة الدخول.

**`src/auth/AuthContext.jsx`**
- بخزّن "مين مسجّل دخول" لكل التطبيق.
- لما تفتح الموقع بيرجّع الجلسة إذا الـ token لسا صالح.
- أي صفحة بتقدر تعرف المستخدم بـ `useAuth()`.

### المكونات (`src/components/`)

**`components/Layout.jsx`**
- الإطار الثابت: الهيدر وروابط التنقل.
- رابط الداشبورد بيظهر للأدمن بس.
- الصفحات بتنعرض جوّاه.

**`components/ProtectedRoute.jsx`**
- حارس الصفحات بالواجهة.
- مش مسجّل؟ → صفحة الدخول. مش أدمن؟ → ممنوع.
- ملاحظة: الحماية الحقيقية بالباك إند، هاد بس للتجربة.

**`components/Badges.jsx`**
- الشارات الملوّنة للحالة والأولوية والتصنيف.
- مثال: `urgent` أحمر، `low` رمادي.
- وشارة خاصة للتذكرة اللي ما انصنّفت.

### الصفحات (`src/pages/`)

**`pages/LoginPage.jsx`**
- فورم الإيميل والباسورد.
- بعد الدخول بيرجعك للصفحة اللي كنت بدك إياها.
- بيعرض رسالة خطأ واضحة إذا البيانات غلط.

**`pages/TicketsPage.jsx`**
- جدول كل التذاكر.
- فيه بحث، فلترة (حالة/أولوية/تصنيف)، وصفحات.
- بتضغط على تذكرة → بتفتح تفاصيلها.

**`pages/NewTicketPage.jsx`**
- فورم إنشاء تذكرة (اسم الزبون، إيميله، العنوان، النص).
- بعد الحفظ بتنصنّف تلقائياً بـ AI.
- وبينقلك على صفحة التذكرة.

**`pages/TicketDetailPage.jsx`** (أهم صفحة)
- تفاصيل التذكرة + تغيير الحالة + تعيين موظف.
- زر "Suggest a reply" → رد من AI مع المقالات اللي اعتمد عليها.
- الموظف بعدّل أو بيبعت، والنظام بسجّل إذا عدّل ولا لأ.

**`pages/KnowledgeBasePage.jsx`**
- عرض مقالات المساعدة والبحث فيها.
- الأدمن بيقدر يضيف ويعدّل ويحذف.
- كل ما المقالات أحسن، ردود الـ AI أحسن.

**`pages/DashboardPage.jsx`**
- إحصائيات للأدمن برسوم بيانية (Recharts).
- عدد التذاكر، سرعة الرد، التوزيع، والترند.
- ونسبة ردود AI اللي انبعتت بدون تعديل.

## الصورة الكاملة بسطر واحد لكل مرحلة

1. زبون بيبعت مشكلة → `NewTicketPage` → `routes/tickets.js`
2. التصنيف → `ticketClassifier.js` → Claude → بينحفظ بـ `schema.sql`
3. الموظف بيفتح التذكرة → `TicketDetailPage` → "Suggest a reply"
4. البحث → `knowledgeSearch.js` → الرد → `replySuggester.js` → Claude
5. الموظف بيبعت → `ticket_replies` → الأرقام بتبين بـ `DashboardPage`
